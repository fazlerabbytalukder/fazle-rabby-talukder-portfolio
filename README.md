## ✨ Features

- Smooth scrolling with **Lenis**
- Scroll-driven and entrance animations with **GSAP** and **Framer Motion**
- Projects showcase and experience timeline
- Contact page with a server-side contact API route
- Responsive and optimized for every screen size

## 🧰 Tech Stack

| Area | Tools |
| --- | --- |
| Framework | Next.js (App Router), React |
| Animation | GSAP, @gsap/react, Framer Motion, Lenis |

## 🗺️ Main Routes

| Route | Description |
| --- | --- |
| `/` | Home |
| `/projects` | Projects |
| `/contact` | Contact |
| `/api/contact` | Contact form handler |

## 🚀 Getting Started

```bash
git clone https://github.com/fazlerabbytalukder/fazle-rabby-talukder-portfolio.git
cd fazle-rabby-talukder-portfolio
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.
