User Features

Multi-Wallets

Users can create multiple wallets and manage their funds across different currencies.

Add Money

Users can add money to their wallets from here using any automatic or manual deposit method.

QR Code

Users get a QR code for receiving money and share it with others.

Invoice Payment Link

Users can create invoices and generate a payment link for their invoices and share it with others to receive payments.

Send Money

Users can send money to other users using their wallet balance.

Request Money

Users can request money from other Users.

Gift Codes

Users can generate gift codes and share them with others to redeem them for money.

Wallet Exchange

Users can exchange their wallet balance from one currency to another currency.

Merchant Payment

Users can payment to any merchants using their wallet balance.

Agent Cash Out

Users can cash out from wallet balance to their agent.

Multi-Level Referrals

Users can invite friends and family to join and earn rewards. Our multi-level referral system lets users earn from both their direct referrals and their referrals’ referrals.

Biometric Login

The user can log in instantly using their fingerprint. No need to remember the password.

Withdraw

Users can withdraw their wallet balance to their bank account from the system.

Two Factor Security

The user can enable the two-factor authentication to secure their account.

Support TIcket

Users can create a support ticket to get help from the customer support team.

Agent Features

Multi-Wallets

Agents can create multiple wallets and manage their funds across different currencies.

Add Money

Agents can add money to their wallets from here using any automatic or manual deposit method.

Cash In

Agents can send money to users. For that, Agents will earns commission on every transaction.

QR Code

Agents can get a QR code for cash out transactions.

Withdraw

Agents can withdraw their wallet balance to their bank account from the system.

Two Factor Security

The agent can enable the two-factor authentication to secure their account.

Commission on Cash In & Out Transaction

Agents can earn commission on every cash in and cash out transaction.

Support Ticket

Agents can create a support ticket to get help from the support team.

Merchant Features

Multi-Wallets

Merchants can create multiple wallets and manage their funds across different currencies.

API Keys

Merchants can generate API keys to integrate payment gateway on their website or app to accept payments.

QR Code

Merchants can get a QR code for their wallet and share it with others to receive payments.

Withdraw

Merchants can withdraw their wallet balance to their bank account from the system.

Two Factor Security

The user can enable the two-factor authentication to secure their account.

Support TIcket

Users can create a support ticket to get help from the customer support team.
